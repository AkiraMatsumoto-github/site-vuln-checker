## 1. 名前（拡張の名前）

- 日本語: **サイト脆弱性チェッカー**
- 英語表記（説明文の冒頭で使う）: Site Vulnerability Checker

## 2. 短い説明（132 文字以内）

```
開いているサイトの WordPress・PHP・プラグインなどの構成と版を推定し、既知の脆弱性とサポート終了を赤・黄・緑・情報・不明の5色で表示します。自分のサイトならサイトヘルスから実測値も読み取ります。
```

- 文字数（上の案）: **103 文字**（記号含む・132 文字以内）
- 禁止表現を避ける: 「安全」「危険」と断定しない／「WordPress」を名前に使わない

## 3. 詳細説明

```
サイト脆弱性チェッカー（Site Vulnerability Checker）は、開いているページに「すでに表示・読み込みされている情報」だけを使って、サイトの技術構成を推定し、既知の脆弱性とサポート終了を「更新すべきもの」として表示します。判定はお使いの端末内で行い、閲覧 URL をサーバへ送りません。

■ わかること
・サイトの作り（WordPress / Jekyll などの静的サイト）とバージョン
・プラグイン・テーマの名前とバージョン（ページに読み込まれているもの）
・PHP / Web サーバ / データベースのバージョン（サイトが公開している場合）
・JavaScript ライブラリ（jQuery など）
・どのアプリのスクリプトが動いているか（Shopify など。名前だけ）
・該当する既知の脆弱性（CVE）と、影響する Version
・サポート終了（EOL）と、同じ系統の最新版

■ 判定の見方
赤・黄は「攻撃の可能性」と「攻撃時の影響度」の 2 つで決めています。
・攻撃の可能性: 実績あり（実際に悪用された事例あり）＞ 特大 ＞ 大 ＞ 中 ＞ 微
・攻撃時の影響度: 特大 ＞ 大 ＞ 中 ＞ 微
緑は「該当なし」、青は「情報（リスクなし・参考）」、白は「不明（判定できない）」です。「不明」は「安全」ではありません。

■ 使い方
1. 調べたいサイトを開いて、ツールバーのアイコンをクリックします
2. サイドパネルの「このサイトを調べる」を押します
3. 赤・黄・緑・情報・不明の 5 つに分かれて表示されます（0 件の枠はランプが消えます）
4. 自分のサイトなら、WordPress の「サイトヘルス」を開いて同じボタンを押すと、PHP・データベース・停止中含む全プラグインの実測値を読み取ります（自動で「情報」タブへ切り替わります）
5. 版が分かる場合だけ（開発者向け）、「バージョンを入力」を開いて追加できます

■ しないこと
・能動的なスキャン（ポートスキャン、ディレクトリ探索、ログイン試行、攻撃コードの送信）は行いません
・第三者のサイトの管理画面は読みません。認証を突破する機能はありません
・閲覧 URL・ページ内容・サイトヘルスの内容をサーバへ送信しません（照合は端末内）
・リモートコードを読み込みません（MV3 の CSP を維持）

■ データの出典
NVD（NIST）/ GitHub Advisory Database（CC-BY-4.0）/ CISA KEV / FIRST EPSS / JVN iPedia / endoflife.date / WordPress.org Plugin API

■ 免責
判定は公開情報に基づく推定です。サイトの安全性を保証するものではありません。誤りを見つけた場合は下記の窓口までご連絡ください。

■ サポート・プライバシー
不具合・ご意見・異議申立て: https://github.com/AkiraMatsumoto-github/site-vuln-checker/issues
プライバシーポリシー: https://akiramatsumoto-github.github.io/site-vuln-checker/privacy.html
```

## 5. プライバシー実務フォーム（回答文案）

### 単一目的（single purpose）

```
開いているサイトの技術構成と既知の脆弱性を表示すること（閲覧中サイトの診断）。
```

### 権限の用途（permission justification）

| 権限 | 回答文案 |
| --- | --- |
| `sidePanel` | 判定結果をサイドパネルに表示するため。 |
| `activeTab` | 利用者が「このサイトを調べる」を押したとき、そのタブを読むため。 |
| `scripting` | 開いているタブの HTML と読み込み済みリソースの URL を読むため（サイトヘルスの表の読み取りにも使用）。 |
| `tabs` | 対象タブの URL・タイトルを取得し、管理画面トップからサイトヘルスへ移動するため。 |
| `storage` | 索引・入力値・サイトヘルスの読み取り値を端末内に保存するため。 |
| `alarms` | 索引を 1 日 1 回更新するため。 |
| `optional_host_permissions`（`https://*/*`） | サイトごとの許可を任意で求めるため（応答ヘッダとサイトヘルスの読み取り）。拒否しても判定できます。 |

### データ使用（data usage）

```
ユーザーデータを収集しません。閲覧 URL・ページ内容・サイトヘルスの内容は端末外へ送信しません。
外部通信は、自前で配信する脆弱性索引（JSON）の取得のみです。テレメトリは取りません。
第三者への提供・販売は行いません。Limited Use の要件に準拠します。
```

### リモートコード

```
使用しません。取得するのは索引 JSON（データ）のみで、実行はしません。eval / new Function / CDN からの JS 読み込みはありません。
```
