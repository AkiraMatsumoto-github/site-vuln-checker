# 設計: 手入力の「バージョンを入力」欄を削除する

状態: **承認済み（B: `<details>` で畳む）** ／ 2026-10-31（実装済み・未コミット）
対象: 拡張のサイドパネルの UI（手入力欄）、README

## 0. 決定（2026-10-31）

- 手入力欄は**削除せず、`<details>` で既定は閉じる**（開発者だけが開く）
- 見出しは「**バージョンを入力（任意・開発者向け）**」
- 「もう一度許可を求める」(`#grantHeaders`) は**折りたたみの外**へ移動（畳んだままだと見えなくなるため）
- `background.js` のバージョン保存・判定への反映は**そのまま**（手入力が使われなくなっても害はない）

## 1. 目的

サイドパネルの「バージョンを入力（任意）」＝**手入力の UI だけ**をなくす。

- 利用者は自分の PHP / WordPress の版を**把握していない**ことがほとんどで、実測でも入力はほぼ使われていない
- 入力欄があると「入れないといけないのか」と迷わせる（実際は任意）

> **バージョンの仕組みそのもの（保存・判定への反映）は残します。** 消すのは「人が打ち込む欄」だけです。

## 2. 削除するもの（UI のみ）

| 区分 | 対象 |
| --- | --- |
| HTML | `sidepanel.html` の `.versions` セクション（製品の select・入力・「追加」ボタン・チップ一覧） |
| JS（サイドパネル） | `renderVersions` / `loadVersions` / `addVersion` / `PRODUCT_LABEL`、チップ削除・Enter・「追加」のハンドラ |

## 3. 変更しないもの

| 区分 | 理由 |
| --- | --- |
| `background.js` の `versions` / `setVersion` メッセージ、`applyVersions`、`chrome.storage` の保存 | **バージョンを判定に使う仕組みは残す**（今回は手入力の入口だけを外す） |
| サイトヘルス・`X-Powered-By` からの版の取得 | 従来どおり |
| 判定・レポート・CLI | 変更なし |

※ 手入力が無くなると `writeVersion` は未使用になりますが、**今回は残します**（次回まとめて掃除）。

## 4. 残すもの（見落とし注意）

**ヘッダ許可の「もう一度許可を求める」リンク（`#grantHeaders`）は、いまバージョン欄のヒントの中で表示しています。**
欄を消すと導線が消えるため、**判定結果の下（状態メッセージの近く）へ移動**します。

```html
<!-- 移動先のイメージ: 状態メッセージの下 -->
<p class="hint">
  サイトが PHP の版を公開している場合だけ読めます（実測 10%）。
  <button id="grantHeaders" type="button" class="link" hidden>もう一度許可を求める</button>
</p>
```

`#grantHeaders` の JS（`showRetryLink` / `retryHeaderPermission`）はそのまま使えます。

## 5. 影響（正直に）

- **手入力で版を補っていた使い方はできなくなります**（社内で版を把握しているケース）
- PHP の版が分からないサイトは「不明」のまま（現状と同じ。EOL 判定はできません）
- README の「バージョンを入力」手順を削除。`store/README.md` の「赤を出す手順」も**入力に依存しない方法**へ
  （古い PHP を使っている検証環境で撮る／サイトヘルスで実測値を出す）
- スクリーンショット `01-red.png` は**入力欄が写っている**ので撮り直し（または下部をトリミング）

## 6. 代替案

| 案 | 内容 | 長所 / 短所 |
| --- | --- | --- |
| **A. 手入力 UI を削除**（提案） | 欄とハンドラだけ撤去。仕組みは残す | 画面がすっきり／手入力の手段がなくなる |
| B. `<details>` で畳む | 「版が分かる人向け」に隠す | 開発者は使える／画面の掃除にならない |
| C. A ＋ 未使用コードも削除 | `writeVersion` / `setVersion` / `VERSIONS_KEY` まで撤去 | コードがきれい／変更範囲が広がる（保存済みデータの移行が必要） |

## 7. 実施内容（B で実装）

1. `sidepanel.html`：`.versions` を `<details>` に変更（`<summary>バージョンを入力（任意・開発者向け）</summary>`）。
   `#grantHeaders` は **`</details>` の外**へ移動
2. `styles.css`：`details.versions > summary` を以前の `h2` と同じ見た目（下線・muted・12px）に
3. `sidepanel.js`：変更なし（`#product` / `#version` / `#addVersion` / `#versionList` の id はそのまま）
4. `sidepanel.test.mjs`：「details で畳む」「許可リンクは折りたたみの外」を追加
5. `README.md` / `extension/README.md`：「版が分かる場合だけ（開発者向け）」に表現を変更、
   `store/README.md` の撮り方は**入力に依存しない**手順へ
6. `manifest.json`：0.4.7
