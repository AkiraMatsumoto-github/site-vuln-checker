プライバシーポリシー

対象: Chrome 拡張「サイト脆弱性チェッカー」（Site Vulnerability Checker）
制定日: 2026-10-29 ／ 最終更新: 2026-10-30

要点: 閲覧している URL・ページの内容・入力したバージョンを、サーバへ送りません。 判定はすべてお使いの端末内で行います。テレメトリ（利用状況の収集）も行いません。 外部通信は、脆弱性の一覧表（索引）を配信元から取得する 1 種類だけです。

1. このポリシーが対象とするもの

Chrome ウェブストアで配布する Chrome 拡張「サイト脆弱性チェッカー」（以下「本拡張」）と、 本拡張が取得する脆弱性の索引（以下「索引」）に適用されます。 本ポリシーは、本拡張をインストールして利用する方、および本拡張が表示の対象とする ウェブサイトの所有者の方を対象にしています。

2. 収集しない情報

本拡張は、次の情報を収集せず、端末外へ送信しません。

  • 閲覧しているページの URL、ページの本文、スクリーンショット
  • ページから読み取った技術情報（WordPress・プラグイン・テーマ・PHP・JavaScript ライブラリの名前とバージョン）
  • WordPress の管理画面「サイトヘルス」から読み取った内容（PHP・データベース・プラグインのバージョンなど）
  • アカウント情報、Cookie、入力フォームの内容
  • IP アドレス、位置情報、端末の識別子、利用状況（テレメトリ・クラッシュレポート）

本拡張には、利用者を識別する機能（ログイン・アカウント・解析タグ）がありません。 広告・行動ターゲティングも行いません。

3. 端末内に保存する情報

本拡張は、動作のために次の情報をお使いの端末内（Chrome の拡張機能用ストレージ）にのみ保存します。 いずれもサーバへは送信しません。

保存する内容 目的 保存先と削除方法
索引（advisories.json）と最終取得日時 通信を減らし、取得できないときでも判定するため chrome.storage.local／拡張を削除すると消えます
入力した PHP などのバージョン（サイトごと） 次回以降も同じ条件で判定するため chrome.storage.local／画面の「×」で削除できます
「サイトヘルス」から読み取った値（サイトごと・読み取り日時つき） 外部からは見えない PHP などの実測値を使うため chrome.storage.local／拡張を削除すると消えます
直前の判定結果 パネルを開き直したときに再表示するため chrome.storage.session（ブラウザを閉じると消えます）

4. 外部との通信

通信 内容 送信する情報
索引の取得
https://akiramatsumoto-github.github.io/site-vuln-checker/advisories.json 		「このサイトを調べる」を押したとき（最短 5 分間隔）と、1 日 1 回の定期更新。 変化が無ければ 304 が返るだけで本文は取得しません 送信するのは更新確認用のヘッダ（ETag）だけです。 URL・ページ内容・判定結果・入力値は含みません。
調べているサイトへの HEAD 要求 利用者がそのサイトへのアクセスを許可した場合だけ、サーバが公開している X-Powered-By などの応答ヘッダを読むために 1 回だけ送ります （本文は取得しません。許可しなくても判定できます） 通常のブラウザと同じ要求です。Cookie は送りません（credentials: "omit"）。 管理画面（wp-admin など）やサイトヘルスの画面では送りません。

上記以外の宛先への通信は行いません。第三者への提供・販売・共有は行いません。 本拡張はリモートコード（外部から読み込んだ JavaScript）を実行しません。索引はデータとしてのみ扱います。

5. 権限とその用途

権限用途
sidePanel判定結果をサイドパネルに表示するため
activeTab / scripting 利用者が「このサイトを調べる」を押したとき、そのタブの HTML と読み込み済みリソースの URL を読むため
tabs調べる対象のタブの URL とタイトルを取得するため
storage索引・入力値・サイトヘルスの読み取り値を端末内に保存するため
alarms索引を 1 日 1 回更新するため
optional_host_permissions（https://*/*） 上記の HEAD 要求のために、サイトごとの許可を任意で求めるため（拒否できます）

6. 第三者のウェブサイトを調べる機能について

  • 本拡張は、誰でも閲覧できる公開ページに表示・読み込みされている情報だけを読み取ります。
  • ポートスキャン・ディレクトリ探索・ログイン試行・攻撃コードの送信などの能動的なスキャンは行いません。
  • 第三者のサイトの管理画面は読みません。 「サイトヘルス」の読み取りは、利用者が自分でログインしている画面に表示されている値を読むだけで、 認証を突破する機能はありません。
  • 判定は公開情報に基づく推定であり、サイトの安全性を保証するものではありません。

7. データの出典とライセンス

索引は次の公開データから作成しています（いずれも再配布可能な条件で公開されているものです）。

  • NVD（NIST National Vulnerability Database）
  • GitHub Advisory Database（CC-BY-4.0）
  • CISA KEV（Known Exploited Vulnerabilities カタログ）
  • FIRST EPSS（Exploit Prediction Scoring System）
  • JVN iPedia（JVN）
  • endoflife.date（サポート終了情報）
  • WordPress.org Plugin API（プラグイン名とバージョンの対応）

本拡張のプログラムは MIT ライセンスで公開しています。

8. 免責

本拡張の判定は推定です。正確性・完全性・最新性を保証しません。 「不明」は「安全」ではありません。本拡張の利用により生じた損害について、開発者は責任を負いかねます。 重要な判断は、ベンダの公式情報や専門家の確認とあわせて行ってください。

9. お問い合わせ・異議申立て

不具合の報告、ご意見、および掲載内容に関する異議申立て（ご自身のサイトについて 判定の訂正・掲載停止をご希望の場合など）は、次の窓口で受け付けます。

  • 窓口: GitHub Issues
  • 異議申立ての際は、対象の URL・該当箇所（どの表示についてか）・ご希望（訂正／削除）をお書きください。 手元で確認できない点がある場合は、こちらから追加の確認をお願いすることがあります。
  • 公開の場に置きたくない内容が含まれる場合は、その旨をお書きください。個別の連絡方法をご案内します。
  • 受付から3 営業日以内の初回応答を目安とします（個人運営のため、遅れる場合があります）。

10. 本ポリシーの改定

機能の追加や法令の変更に応じて、本ポリシーを改定することがあります。 改定した場合は、このページの「最終更新」とリポジトリの変更履歴でお知らせします。 重要な変更がある場合は、拡張の更新情報でもお伝えします。

11. 準拠する方針

本拡張は、Chrome ウェブストアのユーザーデータポリシー（Limited Use の要件を含む）に従います。 取得した情報を、本拡張の機能提供以外の目的に利用することはありません。
